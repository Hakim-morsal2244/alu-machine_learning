# Neural Style Transfer

This project implements Neural Style Transfer using TensorFlow.

## Files

- `0-neural_style.py` - Neural Style Transfer model and image preprocessing.
- `0-main.py` - Test file for the implementation.
- `golden_gate.jpg` - Content image.
- `starry_night.jpg` - Style image.

## Requirements

- Python 3
- NumPy
- TensorFlow
- Pillow

## Usage

Run the test with:

```bash
python 0-main.py
